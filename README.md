# 🚀 ShareInfoQR

**ShareInfoQR** is a user-friendly web application designed to generate QR codes for effortlessly sharing personal or professional information, such as your name, phone number, email, or website URL.

Built with **Vue.js** and deployed on **GitHub Pages**, this project exemplifies the power of AI-assisted development in streamlining the creation process from UI design to deployment.

## 🌟 Features

- 🔲 **Instant QR Code Generation**: Quickly create QR codes for various types of contact information.
- 📱 **Responsive Design**: Optimized for both desktop and mobile devices.
- ⚡ **Fast and Lightweight**: Developed using **Vite** with **Vue.js** for optimal performance.
- 🌐 **Easy Deployment**: Hosted seamlessly on GitHub Pages for broad accessibility.

## 🛠️ Tech Stack

- **Framework**: [Vue.js](https://vuejs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Deployment**: [GitHub Pages](https://pages.github.com/)
- **AI Tools Utilized**:
  - [ChatGPT by OpenAI](https://openai.com/chatgpt): Assisted in generating code, designing UI components, and resolving bugs.
  - [GitHub Copilot](https://github.com/features/copilot): Provided in-editor code suggestions and automation to accelerate development.

## 📦 Getting Started

### Clone the Repository

```bash
git clone https://github.com/abh1hi/shareinfoQr.git
cd shareinfoQr
```

### Install Dependencies

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
